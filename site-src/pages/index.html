How one call goes

Four steps, about two seconds. If step three fails, step four never happens. Read the details.

1

Ask

The agent calls an item. The gateway answers 402 with the price and where each part goes.

2

Sign

The agent signs one transaction: USDC to the seller, the fee to us. It is not sent yet.

3

Answer

The gateway checks the payment would go through, then gets the seller's answer.

4

Pay

Only now the transaction goes on chain. Once it confirms, the agent gets the answer and a receipt.
