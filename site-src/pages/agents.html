Give your agent a budget

You let your agent's key spend up to a limit from your USDC. The money stays in your wallet until it is spent, the chain refuses anything past the limit, and you can revoke it any time.

Set or revoke

One signature in Phantom. No deposit.

Check any wallet

The budget is on chain, so anyone can read it.

Install the kit

A command line, a small SDK and an MCP server. The key it makes only signs payments, one call at a time, inside the price limit you give it.

Command line

Node 20 or newer.

npm i -g github:
bodega init                  # makes the agent key
bodega owner <your wallet>   # pay inside the budget above
bodega limit 0.10            # most it signs for one call
bodega shelf
bodega buy sol-wallet address=<wallet>

No budget? Send a few USDC to the agent's own address and skip owner. It then pays from its own wallet.

MCP server

For Claude, Cursor or any MCP client.

{ "mcpServers": { "bodega": {
  "command": "npx",
  "args": ["-y", "github:", "mcp"]
} } }

Tools: bodega_shelf, bodega_budget, bodega_buy. Run bodega init once first.
